# Octanet Python ATM Task

A beginner-level, command-line ATM simulation written in Python.

## Features

- Demo PIN check with a limited number of attempts
- Balance enquiry
- Cash withdrawal with positive-amount and available-balance checks
- Cash deposit with positive-amount validation
- Invalid menu and amount input handling
- Exit option

## Run

Requires Python 3.

```bash
python "PYTHON TASK 1 ATM.py"
```

The demo PIN is `2005` and the starting balance is `78000`. Both are sample values defined in the source code.

## Important scope note

This is a simple in-memory educational simulation. The balance resets when the program exits. The current project does not connect to SQL or another database, does not persist transactions, and is not a real banking application.
